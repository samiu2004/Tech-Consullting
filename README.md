# TechConsulting starter website

Ten static HTML pages, shared CSS and JavaScript. No install or build is needed for hosting.

## Preview
Open index.html, or serve this folder with a local static server.

## Edit
Page content is in the HTML files. Shared appearance is in assets/site.css; motion, mobile navigation, and directory filters are in assets/site.js. The original prototype is preserved locally in archive/prototype.html and remains available in GitHub commit history. Edit the HTML and shared assets directly; no generator or build command is needed.

## GitHub to Cloudflare Pages
Upload the HTML files and assets folder to your repository. Create a new Pages project with Git integration, connect the repository, and choose its actual production branch. Select no framework, leave the build command empty, and use the repository root as the output directory (usually /). Preview the pages.dev address before moving your domain. In the new project's Custom domains screen, add the existing domain and follow Cloudflare's instructions; remove the old project association when required. A Direct Upload Pages project cannot be converted to Git integration.

Do not remove your existing live deployment before the new preview works. Never upload credentials. Repository files can be updated separately from hosting; changing GitHub does not connect Cloudflare or move your domain.

## Publishing checklist
Replace the contact notice with an actual channel before public launch. Verify provider links and regional availability. No news, prices, programme eligibility, product scores, analytics, newsletter signup, or affiliate tracking are supplied. Update policies to reflect actual services you add.

## Roadmap
1. Review the ten page layouts and directory filters.
2. Configure a real contact channel and accurate policies.
3. Publish one sourced update, one tested comparison, and one complete practical guide.
4. Verify the Git-connected preview and then attach the domain.
5. Add clearly disclosed affiliate links only after joining provider programmes.

The ten-page launch combines editorial, affiliate, privacy, and terms information on policies.html. Future articles can have individual URLs; these add to the total page count.
