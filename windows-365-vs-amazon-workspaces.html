Cloud desktops & RDP / A considered comparison

Windows 365 vs Amazon WorkSpaces: do you need a cloud desktop?

Compare hosted desktops for client work: when they help, costs, application access and why a cloud desktop differs from a VPN or basic RDP hosting.

By TechConsulting · Updated 18 November 2026 · Documentation-based

THE DECISION IN BRIEF

Need another computer—or just a different connection?

Windows 365

Consider Windows 365 Business for a per-user Windows Cloud PC with a monthly subscription.

WorkSpaces

Consider Amazon WorkSpaces Personal when AWS configuration and running-mode choices fit your team.

What are you actually buying?

A cloud desktop is a computer running in a provider’s infrastructure. Your screen shows its desktop, while applications execute there. That can give a contractor a separate work environment without buying another physical laptop.

RDP means Remote Desktop Protocol: a way to connect to a remote computer, not a provider or a complete hosting plan. Windows 365 and Amazon WorkSpaces are managed desktop services; do not assume they have identical connection protocols or features. A cheap server advertised as “RDP” is a different purchase with different administration and licensing responsibilities.

When is a remote desktop useful?

Consider one when a client wants work performed in its managed environment, you need supported applications away from your main device, or you want a consistent desktop when switching computers. Keeping files within a managed desktop can reduce casual local copies, but only if clipboard, drive and download permissions are configured appropriately.

If you already have a suitable computer and only use browser-based tools, a cloud desktop may add cost without enough benefit. For occasional support of someone else’s existing PC, evaluate a permission-based remote-support tool instead of renting a new desktop.

Which sites or applications need it?

A normal browser website does not inherently require RDP. The need usually comes from the client’s environment: an internal Windows application, a private file share or a portal accessible only from its managed network.

A rented desktop is not automatically inside that network. Ask the client to provision or approve the environment, accounts and route. Do not assume buying a desktop in another country grants access to a banking site, a marketplace or an advertising account. Location checks, identity requirements and account permissions still apply.

What will the bill look like?

Microsoft’s checked US page lists a Windows 365 Business configuration with 2 vCPU, 8 GB RAM and 128 GB storage at $36 per user per month on an auto-renewing monthly subscription. This is one configuration, not a universal starting price. Confirm local pricing, tax and any applicable eligibility conditions.

AWS WorkSpaces Personal offers different running modes. AutoStop charges include a fixed monthly component plus hourly usage; stopping the desktop does not eliminate the fixed component. Price the selected region, operating system and bundle before comparing it with a flat subscription. We are not quoting one AWS price for every configuration.

Also budget for applications, backups, identity and network services where applicable. “Supports Microsoft 365 apps” does not mean every Microsoft 365 application licence is included. Confirm the licences for the software you intend to run.

The connection still matters

A cloud desktop does not solve an internet outage. Your local connection must carry the remote session. Distance to the hosting region, latency and packet loss can affect typing, calls and screen updates. A basic office configuration is not evidence that video editing or 3D work will perform well.

Pilot with your actual applications and a representative file. Check reconnecting after a dropped connection, audio, display scaling and authorised file transfer. Confirm who manages updates, recovery and account removal when a contract ends. These are suggested checks, not measured results.

Our decision

Shortlist Windows 365 Business when its Windows subscription and administration fit. Shortlist WorkSpaces Personal when AWS configuration and billing options suit your team. If the client mandates its own desktop, use that approved environment. If you only need connection privacy, a VPN may be the smaller, more appropriate purchase.
